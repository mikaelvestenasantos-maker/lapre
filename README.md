# LAPRE: Avaliação, Prevenção e Reabilitação Esportiva

Aplicativo da Liga de Avaliação, Prevenção e Reabilitação Esportiva (UFSM) para estudantes de fisioterapia.

**Acesse:** https://mikaelvestenasantos-maker.github.io/lapre/

Funciona sem internet depois de aberto uma vez. No celular, abra o link e use "Adicionar à tela inicial".

## O que tem
Testes de avaliação, exercícios com passo a passo, protocolos por fases, prevenção (FIFA 11+ e outros),
anatomia e biomecânica, casos clínicos, questionários com pontuação, calculadoras e registro de pré-temporada.

## Avisos
- Conteúdo educacional **em rascunho**: precisa de revisão do professor orientador e não substitui o julgamento clínico.
- Não guarda dados de pacientes: tudo o que é digitado fica só no aparelho. Use apenas código ou iniciais, nunca o nome completo.
- Os questionários DASH, QuickDASH e Oxford Shoulder Score não estão nesta versão, porque dependem de licença dos autores.
